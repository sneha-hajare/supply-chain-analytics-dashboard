# Supply Chain Analytics Dashboard

## Project Overview
The Supply Chain Analytics Dashboard is a Java-based web application designed to monitor inventory, manage suppliers and orders, analyze supplier performance, and forecast future demand.

## Features
- Supplier management (add, view, edit, and delete)
- Inventory management
- Supply order management
- Demand forecasting
- Supplier analytics
- Dashboard with key performance indicators (KPIs)
- Database integration using MySQL
- Web interface using Thymeleaf and Chart.js

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Spring Security
- Chart.js
- Maven
- HTML and CSS

## Database
Database name: `supplychain_db`

Import the provided `supplychain_db.sql` file into MySQL to set up the database.

## How to Run
1. Install Java and MySQL.
2. Configure the database connection in `src/main/resources/application.properties`.
3. Open the project in IntelliJ IDEA.
4. Run the Spring Boot application.
5. Open the application at `http://localhost:8080` (unless another port is configured).
